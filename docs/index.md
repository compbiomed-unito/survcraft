# SurvCraft

SurvCraft builds survival prediction models with PyTorch and scikit-learn-style
estimators. Combine a feature network, a survival distribution, and a training
loss to model right-censored time-to-event data.

This site documents the repository's default branch. It may describe changes
that are not yet included in the latest PyPI release. SurvCraft is an alpha-stage
research library; its public APIs may change.

Start with the quick start, then read the model and data conventions. The API
reference is generated from the Python docstrings.
